# Contributing

Thanks for suggesting a tool. This list only covers open-source SaaS products: applications a team can
self-host or use as a hosted service, as an alternative to a closed-source product.

## Inclusion criteria

A pull request is merged only if the project meets **all** of these:

1. **It is a SaaS product.** A complete application that people sign in to and use, either self-hosted
   or hosted. Libraries, SDKs, CLIs, browser extensions, MCP servers, single-purpose utilities, agencies,
   consultancies, directories and other awesome lists are out of scope.
2. **It is open source.** The main repository is public and carries an OSI-approved license.
3. **At least 50 GitHub stars** on the main repository, gained organically. Projects with bought or
   botted stars are rejected.
4. **At least 6 months old.** The main repository must have been created at least 6 months before the
   pull request is opened.
5. **Actively maintained.** There are commits in the last 6 months.

## Formatting

- Add one row to the section that fits best, and don't change other rows.
- Link the star badge to the project's main repository, not to a GitHub organization:
  `<a href=https://github.com/OWNER/REPO><img src="https://img.shields.io/github/stars/OWNER/REPO?style=social" width=150/></a>`
- Name at least one closed-source product it replaces in the "Closed-Source Alternatives" column.
- Check that every link in the row works.
- If you work on the project, say so in the pull request.

Pull requests that don't meet these criteria are closed.
